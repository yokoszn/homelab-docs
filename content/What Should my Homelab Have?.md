## Security Tips to Get Started

1. Don't pirate software.
2. Always have your Admin Account seperate from your daily driver account.
3. Use time based multi-factor on critical accounts like e-mail.
4. Use a password manager and have unique passwords for everything.
5. Use passphrases when able. Example: 1DeerCloudSubmarine91* [XKCD Password Generator](https://xkpasswd.net/s/).

Avoid Directly Exposing Ports, Ideally Use a VPN. if you must, implementing a DMZ (De-militarized Zone) [[Reverse Proxy]], Cloudflare Tunnel, etc.
Use VPN Wireguard/OpenVPN or Pangolin (Newt Tunnel)
