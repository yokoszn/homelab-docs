[[NPMplus]] vs [[Pangolin]]

---

| Feature           | Pangolin                | NPM+ (Nginx Proxy Manager)  |
| ----------------- | ----------------------- | --------------------------- |
| OIDC / SSO        | ✅ First-class           | ❌ Plugin-dependent / clunky |
| Config as Code    | ✅ JSON + UI hybrid      | ❌ Mostly GUI                |
| Lightweight       | ✅ Single binary (Rust)  | ❌ Full Docker stack with DB |
| Dev Activity      | ✅ Active                | ⚠️ NPM+ often stale         |
| Cloudflare Tunnel | ✅ Supported as upstream | ✅ Also supported            |
